## 1. 登录 CMS 后台

1. 打开浏览器，访问前端站点：**http://localhost:4321**（生产环境为官网域名）
2. 在地址栏末尾加上 `/login`，访问 **http://localhost:4321/login**
3. 输入管理员账号密码登录（例如：用户名 `admin`、密码 `admin`）
4. 登录成功后，页面右上角会出现编辑相关按钮，标题下方出现 **EDIT** 按钮

> 登录后即可在网站前台直接点击内容进行**原地编辑**（In-Context Editing），无需跳转管理后台。

## 2. 页面内容编辑（原位编辑）

已发布的业务页面（核心能力、学术研究、解决方案等）中的**文字内容**（标题、副标题、引导语、标签、描述等）都支持前台原地编辑：

1. 登录后，进入要编辑的页面（例如 `/coohomcloud/corecompetency`）
2. 移动鼠标到要修改的文字上，会出现蓝色高亮框
3. 点击文字，在弹出的小工具栏中编辑内容
4. 编辑完成后，点击右上角的 **SAVE**（保存），再点击 **PUBLISH**（发布）使其对访客生效

> 📌 **注意**：
> - 论文列表中的标题 / 摘要 / 会议期刊**不支持前台原地编辑**，需通过「管理界面」编辑（见下一节）。
> - 装饰性标识（如 `SPATIALVERSE ENGINE`、`CMS / MEDIA FIELD`）由前端模板固定，不在 CMS 中编辑。

## 3. 新增学术论文（核心操作）

「学术研究」页面 `/coohomcloud/corecompetency/paper` 的论文来自 CMS 中的论文条目（Piece），需要**两步**：先在「论文库」中创建新论文，再把新论文关联到页面。

### 第 1 步：在论文库中新建论文

1. 登录 CMS 后台
2. 打开 **学术研究** 页面：`/coohomcloud/corecompetency/paper`
3. 点击页面上的 **EDIT** 按钮（左上角）
4. 在弹出菜单中选择 **三点（More Options）** — 即 `···` 按钮
5. 在更多选项中点击 **Edit**（进入该页面在 CMS 管理端的编辑界面）
6. 向下滚动，找到 **关联论文（Papers）** 区块
7. 点击 **Browse**（浏览）按钮，打开论文选择器
8. 在论文选择器中点击 **New Paper / 新建论文**（或 **+ New**）按钮

> 如果论文选择器中没有「新建」按钮，也可从后台「内容」→「论文」直接新建，步骤相同。

### 第 2 步：填写新论文信息

在新建论文的表单中填写以下字段：

| 字段 | 说明 | 是否必填 |
|---|---|---|
| **Title 标题** | 论文的完整标题（显示在列表卡片上） | ✅ 必填 |
| **Year 年份** | 四位数年份，如 `2022`（列表按年份降序排列） | ✅ 必填 |
| **Venue 会议 / 期刊** | 发表会议或期刊名称 | ✅ 必填 |
| **Abstract 摘要** | 论文摘要（显示在列表卡片上） | 可选 |
| **External URL 外链** | 论文的外部链接（如论文主页、DOI、ArXiv） | ✅ 必填 |
| **Cover 封面图片** | 论文封面图（当前列表暂未渲染封面，可为空） | 可选 |

> 📌 **完成字段填写后，务必先「保存（Save）」，再「发布（Publish）」**，否则访客看不到这篇论文。

### 第 3 步：把新论文关联到学术研究页面

新论文创建并发布后，需要把它关联到「学术研究」页面，访客才能看到：

1. 回到学术研究页面的编辑界面（`/coohomcloud/corecompetency/paper` → EDIT → `···` → Edit）
2. 向下滚动到 **关联论文（Papers）** 区块
3. 点击 **Browse** 打开论文选择器
4. 勾选刚创建的新论文（以及任何其他需要展示的论文）
5. 确认选择后，论文会出现在「关联论文」列表中；可拖拽调整展示顺序
6. 点击页面右上角 **SAVE（保存）**，然后点击 **PUBLISH（发布）**

### 第 4 步：验证前台展示

1. 打开或刷新站点前台：`/coohomcloud/corecompetency/paper`
2. 确认新论文出现在列表中（按年份降序）
3. 点击论文卡片，确认外链跳转正常

## 4. 新关联 / 重新排序论文

如需调整学术研究页展示的论文集合或顺序：

1. 登录 → 打开 `/coohomcloud/corecompetency/paper` → **EDIT** → `···`（更多选项）→ **Edit**
2. 下滑到 **关联论文（Papers）** 区块
3. 点击 **Browse**，勾选/取消勾选要展示的论文
4. 在关联列表中**拖拽**调整顺序（注意：前台最终按年份降序渲染）
5. **Save** 保存 → **Publish** 发布

---

## 5. 发布与预览

- **Save（保存）**：保存为草稿，仅登录用户可见
- **Publish（发布）**：让内容对访客公开可见
- **Preview（预览）**：在发布前查看草稿效果

> ⚠️ **重要**：只保存不发布，访客访问页面会看到旧内容或 404。**每次编辑完都要记得点击 Publish。**

## 6. 常见问题（FAQ）

### Q1：新论文创建了，但前台列表看不到？

- 检查论文是否已 **Publish（发布）**（仅保存草稿访客看不到）
- 检查论文是否已 **关联到学术研究页面**（第 3 步）
- 检查论文是否在「关联论文」列表中被勾选

### Q2：前台论文顺序不对？

- 学术研究列表**按年份降序**渲染（最新年份在前）。关联列表中的顺序会被年份排序覆盖。

### Q3：论文卡片的标题/摘要可以前台点击直接改吗？

- 不能。论文的 `title` / `abstract` / `venue` 属于论文条目字段，目前仅支持在 CMS 管理端编辑（EDIT → `···` → Edit → 下滑到关联论文 → Browse → 点论文进行编辑）。

### Q4：找不到「新建论文」按钮？

- 在论文选择器的搜索框旁通常有 **+ New Paper** 或 **New** 按钮。若仍未显示，可从后台侧边栏「内容 → 论文」中新建。

### Q5：修改页面文字后没有生效？

- 需要先 **Save** 再 **Publish**。原地编辑只在登录状态下高亮可编辑区域。
